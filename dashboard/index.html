    Symbol Ranking — by CAGR / max drawdown

    Every symbol on a given timeframe shares that timeframe's window, so ranking within a timeframe is a clean like-for-like comparison — era differences cancel out. Filter to one timeframe before picking candidates.

    Click any column header to sort. Greyed rows fall below the min-trades threshold — ranked but not trustworthy.

    Reference · Same-Window Comparison secondary view — truncates slow timeframes to tiny samples

    Restricts every timeframe to the same trailing window. Kept for reference only: it costs the slower timeframes most of their data (1D falls to ~23 trades over 12 months, barely one per symbol), so it is a weaker basis for selection than CAGR/DD over full history. TradingView's bar limit means the longer histories simply do not exist at fast timeframes.

    Portfolio Simulation

    Replays the logged trades through a capacity-limited account. Position slots are a scarce resource — a symbol with a great CAGR contributes nothing if its signals always arrive while every slot is full, and portfolio drawdown depends on how many positions are losing at the same time, which no per-symbol statistic captures.

    Reads trade-log/*.csv only — no TradingView connection needed.
